=== PROVENANCE IS MANDATORY (principal 2026-08-07 -- it is what makes cross-region convergence mean anything) ===
The desk elevates a mechanism when researchers in UNRELATED ecosystems arrive at it independently:
different data, different venues, different regimes, same conclusion. That is a genuinely strong
prior -- and it is the easiest false signal this desk could build, because ecosystems are NOT
independent. Three regions describing one effect are, more often than not, THREE READINGS OF ONE
ENGLISH PAPER, and ideas propagate outward from the arXiv / SSRN / WorldQuant layer. Counting
echoes as confirmations is GAP #85 (n counting readings of the world, not events in it) aimed
squarely at the number used to promote a mechanism above its evidence.
libs/research/convergence.py can only tell the two apart if YOU record where a finding came from.
So on EVERY mechanism card, record two fields:
  * SOURCE: the citable locator of this specific writeup.
  * DERIVES-FROM: every paper, post, repo or thread it cites, translates, summarises or visibly
    reacts to. If you checked and it cites nothing, write DERIVES-FROM: NONE (checked) --
    explicitly, because an empty field and a checked-empty field are opposite facts and the module
    treats a blank as UNVERIFIABLE rather than as original.
An unverified match elevates NOTHING. It stays a lead, exactly like a singleton.
And when convergence IS genuine it buys a QUEUE PLACE, never a lower bar: ten ecosystems can be
wrong about the same thing, and folk finance is precisely where they are -- a belief is widely held
because it is intuitive, not because it is true. A converged mechanism owes the same
pre-registration, deflation and out-of-sample evidence as one nobody else mentioned.

  survivors while measured NUMBERS converted 4/4 (edge bands, rejection rates, distributions,
  thresholds with stated N). Extract every measured quantity first; a trade idea without a number
  attaches to nothing this desk can test cheaply.
* RANK when the source is noisy; Z-SCORE when it is expensive to move. A large reading from a
  costly-to-move source (swap/carry, futures-curve basis, COT positioning) IS the evidence --
  rank throws it away.
* MEAN-REVERSION FAMILIES RANK LAST FOR RESEARCH EFFORT; spend the marginal mining hour on
  trend/carry/flow before reversion. Three independent methods agreed on that ordering (desk
  permutation, a 350k-backtest sweep, a 10k-trader study). THE ORDERING IS THE FINDING -- the tape
  it was measured on is retired, so carry it as a PRIOR over the MT5 book for the gauntlet to
  re-measure, never as a reason to go back to the retired ground looking for it.

BACKTEST MINER -- a dedicated extraction category. Hunt: backtest, back-tested, backtesting,
Sharpe, Sortino, Calmar, CAGR, drawdown, profit factor, win rate, PnL, equity curve, out-of-sample,
walk-forward, Monte Carlo, paper trading, live results, track record. Then separately search CODE
repositories for actual implementations of the same idea.
RECORD WHETHER COSTS WERE ACCOUNTED FOR -- commission, spread, swap/rollover, slippage, impact,
latency. A backtest that never mentions them is not a weaker result, it is a DIFFERENT QUANTITY
from the one this desk computes: on a retail CFD book the spread and the overnight swap alone
routinely exceed the edge (WS-006 -- a Holm-cleared signal that netted -0.656 bp/bar).
Absence of cost accounting is itself the finding.

TIER EVERY DISCOVERY BY HOW CHEAPLY IT CAN BE KILLED (libs/research/evidence_tier.classify):
  EXECUTABLE         code + data + params -> refutable in an afternoon    <- HUNT THESE HARDEST
  REPRODUCIBLE_SPEC  enough detail to rebuild without guessing            <- one cycle to settle
  MECHANISM_ONLY     an economic story, no numbers                        <- the form that TRANSFERS
  BARE_CLAIM         a headline return                                    <- ore, still worth mining
EXECUTABLE RANKS FIRST BECAUSE IT IS CHEAPEST TO REFUTE, NOT BECAUSE CODE IS MORE HONEST. Published
bot code is if anything MORE overfit than an anecdote -- it was tuned until the curve looked good.
The reason to hunt it first is that the desk can SETTLE it instead of arguing about it.

CLAIMED IS NOT VERIFIED. A post saying "my XAUUSD EA made 40% last month" is RESEARCH ORE, never
evidence, however precisely it is stated -- precision is the property fabrications have most. Record
the claim in the claimed column and leave verified EMPTY; only a run on this desk's own data fills
it. If code and data exist, say so loudly: that is a reproduction the desk can actually attempt. If
they do not, extract the MECHANISM and hand it up as a hypothesis instead -- an unreproducible claim
still carries a testable idea.

TRANSLATE, DO NOT COPY (libs/research/evidence_tier.translate_to_mt5). A foreign result copied
verbatim is untestable here; its MECHANISM usually has an exact MT5 analogue this desk already
records. futures basis -> dated front/next futures curve + annualized roll yield. roll yield ->
the same curve. carry -> point-in-time MT5 long/short swap plus futures-curve carry. commitment of
traders -> point-in-time CFTC COT hedging pressure by mapped future. sector/industry neutral ->
neutralize by MT5 asset class and currency-risk bucket. order imbalance -> broker-native bid/ask
tick-change imbalance (DOM only when the DOM is real). market maker inventory -> quote asymmetry
and spread-state proxy, never an invented dealer book. cross-sectional momentum -> rank returns
across contemporaneous Fusion MT5 symbols. flight to quality -> gold, USD, JPY, CHF, rates and
equity-index relative-state basket. THIS is what makes the international miners worth more than
scraping strategies: the idea arrives in another market's vocabulary and the translation is the
desk's edge. A mechanism with NO MT5 expression is not a find -- it is a graveyard row stating
which instrument would have been needed.

CLASSIFY EVERY DISCOVERY as: mechanism -> hypothesis -> evidence -> failure/success -> data source
-> reproducibility. Collecting "profitable bot" claims without that structure is not mining.
