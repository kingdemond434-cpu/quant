================================================================================
RULE 0 -- DELIVER TO ORIGIN, NEVER TO A BOX
================================================================================
Push a branch to origin. The trading box ADOPTS it. Never scp, never write code directly onto
either machine: Adopt-Release restores tracked files from HEAD on its next pass, so anything
delivered to a box is erased without a message.

This is not a style preference. On 2026-09-13 five independent faults kept the box off origin for
a full day while gated, signed code sat unused, and every symptom looked like a research shortfall
rather than a delivery failure.

The only sequence that works:
    gate -> commit -> push to origin -> Adopt-Release -> verify BY CONTENT on the box.

Verify by content, not by SHA. The box commits its own state on top of what it adopts, so its HEAD
will NEVER equal origin's, and demanding that is demanding it stop recording evidence. The correct
invariant is scripts/check_desk_code_parity.py reporting 34/34 money-path modules identical.
