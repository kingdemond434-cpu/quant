The user adopted an **Institutional Quantitative Research Constitution** as the standing operating framework for the quant platform. It generalizes (does not replace) the honesty mandate in [[crypto-desk-state]] and [[research-strategy-pivot]].

**Master objective:** maximize expected *lifetime geometric growth* (E[log wealth] / Kelly utility), subject to statistically-justified survival constraints. Sharpe/CAGR/drawdown/infra are proxies — never optimize them directly.

**Why:** every downstream decision (what to build, what to deploy, how much leverage) should be justified by expected contribution to terminal wealth, not local metrics.

**How to apply:**
- **Engineering = capital.** Every task competes on Engineering ROI = impact_on_log_growth × p_success / effort. Never build below the best available alternative's ROI. Never rewrite a subsystem unless profiling shows it's a real bottleneck. Reuse existing modules (compose, don't duplicate). Delete depreciating legacy.
- **Profile before optimizing.** Each cycle: audit throughput/debt/decay/capacity/bottlenecks first, then act only on the top-ROI item.
- **Validation is a HARD gate, never weakened:** Walk-Forward, CPCV, Deflated Sharpe, White Reality Check, PBO, capacity, correlation, execution-cost, marginal contribution, uncertainty. Never use forward info. Never fabricate alpha. Most candidates should fail.
- **Alphas decay** — carry a retire_check, half-life, and crowding estimate, not just a promote_check. Research is continuous replacement.
- **Portfolio:** optimize only E[log wealth] subject to survival/liquidity/costs/correlation/capacity. Allocate by marginal contribution to portfolio utility, never standalone Sharpe.
- **Persistent state files** (repo root): `research_state.json`, `engineering_backlog.json`, `alpha_pipeline.json`, regenerated by `scripts/research_cycle.py` each cycle — remove completed, add new bottlenecks, recompute ROI, remember decisions.
- The constitution itself is mutable: propose the higher-ROI version when faithful to the master objective.

**Capital Deployment Principle:** research has zero economic value until deployed. Maximize the *statistically-justified deployment rate*, not research perfection. Deploy the instant EV(deploy now) > EV(wait for more validation) — over-validation / deployment delay destroys log-growth exactly like under-allocation does. Deploy early ≠ deploy unvalidated size.
