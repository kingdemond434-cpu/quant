**Key v1.0 decisions (act as source of truth unless user revises):**
- Single Windows VPS; ONE codebase, three run modes (`research`/`trade`/`ops`). No microservices, no Redis bus, no Airflow, no FastAPI registry service, no MLflow server, no hot-standby failover.
- Stores: **SQLite** (ACID system-of-record: registries, hash-chained trials ledger + audit, orders, risk) + **Parquet lake + DuckDB** (analytics, mandate-preferred). artifacts/ folder replaces MLflow.
- Structural invariant kept: "risk overrides alpha" — no order without a persisted `risk_approval_id` (type + DB constraint).
- **Edge-first build order**: MVP = stages 1–7 (skeleton/contracts → SQLite store → data/lake → cost model → backtest engine **cross-validated vs vectorbt/backtrader** → features PIT/parity → validation gauntlet). Then a hard MILESTONE: prove ONE pre-registered economically-grounded edge under pessimistic costs (2–5×), trials inflated ×5–10, locked holdout. FAIL → honor pre-committed project kill criteria (`config/project_charter.yaml`), STOP. Trading estate (risk gate, execution, portfolio, lifecycle, monitoring) only built AFTER milestone passes.
- Preserved controls: full gauntlet (DSR/PBO/CPCV purge+embargo/walk-forward/reality-check/bootstrap/sensitivity/stressed-TCA/regime/lockbox/FDR) + trials ledger + economic-prior gate; PIT/parity; reproducibility stamp; 16 risk frameworks (fractional Kelly ≤¼, vol target, factor caps, stressed correlation, heat, drawdown governor, gap-aware tail/CVaR, crisis, equity floor, layered+out-of-band kill, escalation); alpha card/lifecycle/decay/retirement; broker reconciliation, idempotency, fail-closed.
- Deferred until multiple validated alphas exist: regime engine, meta-learning, tournament bandit allocator, genetic search (last/optional), attribution/Shapley, failure-correlation engine, full 20-instrument universe (trade XAUUSD alone first).
- Red-team constraints treated as binding: no demonstrated edge yet; self-validation conflict unsolvable solo; complexity is the main solo risk; broker counterparty is an undiversifiable tail (withdraw profits, minimal on-platform capital).
