# L0050

Before trusting any imported statistical construction, push a rule through it that CANNOT have skill. If the zero-skill rule scores significant, the construction is manufacturing the significance and every result from it is inflated.

## Evidence

bar_permutation: the source's two independent shuffles gave buy-and-hold p=0.007 on a null preserving its mean exactly; carrying each gap with its own bar moved it to 0.91. tests/validation/test_bar_permutation_discrimination.py
