# L0214

A 403 is three different verdicts wearing one status code: a §13 wall, a UA-keyed edge rule, or an IP-keyed edge rule. Run two UAs plus an archived-robots read (~10s) before EVER grading a host walled -- a wrong wall shrinks the data universe permanently and leaves no trace.

## Evidence

2026-08-28(l): bankofengland.co.uk/robots.txt 403 under ClaudeBot, 200 under a Chrome UA (357B, /statistics NOT disallowed). rba.gov.au 403 under BOTH UAs (Akamai, IP-keyed) yet archived robots 20260201034831 permits /statistics. rbnz.govt.nz 403 on 4 hostnames/2 UAs/2 schemes yet archived robots 20260131091236 bars only /temp /sitecore /app_data /cdn-cgi /emergency plus GPTBot. Three of four hosts this seat had graded walled were permitted; each wrong grade was a §38 mining regression by attrition.
