# L0244

A deliberately literal mapper needs something upstream that does the naming. ontology.map_to_capabilities matches only text that already names a capability group -- correct, because a fuzzy mapper assigns something to everything and a miner that always finds a capability always finds a gap. But almost nothing in the wild names a group, so real claims mapped to the empty tuple and were admitted to the queue and went nowhere: the same outcome as refusing them, wearing the costume of the opposite.

## Evidence

'guy who used to work there says they run thousands of small models and average them' -> map_to_capabilities returned ()
