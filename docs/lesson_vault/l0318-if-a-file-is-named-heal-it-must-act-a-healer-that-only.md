# L0318

If a file is named heal_*, it must ACT. A healer that only diagnoses is a report with a misleading name, and the gap it names will be read as monitored rather than as open. Check that every detector with a repair in its name actually performs one.

## Evidence

2026-09-14: scripts/heal_forward_lane.py detected certificates authorized to run forward with no clock, named them, exited 1 and enrolled none -- for weeks. 84 certificates sat clockless. Enrolling grants no authority: a forward clock is a shadow lane, so starting one resumes MEASUREMENT and promotion still demands a certificate and a mature clock.
