# L0216

A codelist advertises what the data does not contain. Before building any feature on a documented column, count its non-null observations -- an empty-at-every-timestamp column and a rounded-to-uselessness column both look fully documented in the metadata. And diff every level series against a second door of the same institution: a definitional reclassification appears as a smooth ratio decay plus a one-month cliff, with no null, no unit change and no code change to catch it.

## Evidence

SSB 06833 (run o): code 'A' (reserve assets, mill. USD) carries a full label and unit and ZERO observations at all 316 timestamps; code 14 (gold, millions of fine troy oz) rounds 1.18M oz to '1' -- two verification arms destroyed before one worked. SSB 09468 'Foreign assets, total' goes 4,796,246 -> 357,637 NOK mn in one month (2013M08, -92.5%) as the GPFG is reclassified off the line, unflagged: a MoM-change feature books a fabricated -4.4 trillion NOK outflow, the series' largest apparent capital-flight event.
