# L0338

EVERY GROUND CONVERTS TO CELLS. Any source, ground, feed or forest the desk ever covers must have machinery that turns it into gauntlet cells -- not a collector, not a dashboard tile, not a document saying it is interesting. Adding a name to a source registry feels like progress, costs one line, and is measured by nothing downstream, so source lists grow forever while the docket does not. A ground with NO CONVERTER is a defect (III.16 one layer out); a ground whose converter RAN and yielded nothing is not a defect, that is yield, and yield may be zero. Never conflate the two: failing on a quiet source teaches the next session to delete a real feed for being briefly uninteresting.

## Evidence

scripts/check_ground_conversion.py, 547 grounds gated 2026-09-15: 502 deep-forest + 45 asia-plane, 0 NO_CONVERTER; asia_plane.py converts 45 sources to 393 cells, 393/393 compiling as STRUCTURED_HYPOTHESIS. The rule caught 9 grounds converting to nothing on its first run.
