# L0253

An autonomous implementer is safe when containment is structural rather than promised. It may write only under frontier_intel/challengers/, the check runs on the RESOLVED path so a generated module name carrying '..' cannot walk into gateway.py, every artifact is stamped authority ZERO, and it opens no branch and merges nothing. That keeps the supervisor's original reasoning intact -- an organ that can both propose and merge into the tree that sizes real positions is one bad extraction away from a live defect -- while removing the human courier. A challenger nobody promotes costs a directory.

frontier_intel/implementer.py; 14 tests, 6 of them containment escapes
