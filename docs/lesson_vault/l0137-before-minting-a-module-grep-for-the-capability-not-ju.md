# L0137

Before minting a module, grep for the CAPABILITY, not just the law or the law-id. A defect described in a new row is often one the desk already solved on a different vendor, and the prior art will be filed under that domain word, never under yours.

## Evidence

R0389 shipped revision_report in libs/research/axis_integrity.py while libs/research/vintage.py had done it since R0316 -- and better (as-of VALUES, so as_of(d) reconstructs; mine stored a summary line). Searching "revision" found nothing because the prior art says "vintage". Removed in 8df80793.
