# L0151

Run the falsifier, then falsify the FALSIFIER's own number. A pre-registered falsifier that returns a strong result has not finished -- ask what fraction of it comes from how few observations before you believe it or build on it.

## Evidence

docs/research/capability_hunt/20260813_s4_falsifier_summand_persistence.json: lag-1 rho read +0.856 on M2_oi_growth|h=5 (Bartlett 12.9, would have deflated n_eff 12.9x). 98.1% of the lag-1 numerator came from 5 date-pairs of 310; with a >=10-symbol-per-date floor the answer is -0.06. A fence was nearly built on it.
