# L0073

A rail's reference point and a performance number may NEVER share a source. A ledgered re-base legitimately moves the ruin rail's inception; if P&L reporting reads that same number, the re-base becomes reported profit. Publish both readings and let their gap alarm.

## Evidence

2026-08-05 web/cashcarry_live.json published net_pnl +2938.01 while the venue income ledger (realized -3153.27 + funding 113.06 - commission 1750.88 = -4791.09) said the book had LOST 1869.74. Gap 4807.75 = the 2026-08-01 RESTART re-base 10547.78->5757.08 (+4790.70) plus 17.05 slack. hurdle_rate.py:97 read the inflated field.
