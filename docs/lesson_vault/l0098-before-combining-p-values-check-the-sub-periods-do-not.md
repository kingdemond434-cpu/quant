# L0098

Before combining p-values, check the sub-periods do not overlap. A combination test assumes INDEPENDENCE, and a violated assumption still returns something that looks exactly like a probability -- the one failure no range check catches.

## Evidence

signal_halflife rolling_ic strides 20 through a 60-wide window; fed the overlapping series the mean-p bar read the REFUTED kimchi axis STRENGTHENING at error rate 7.9e-05, and striding to non-overlapping windows dropped it to UNDERPOWERED (2 independent windows)
