# L0331

Copy-trading and retail track-record platforms (darwinex, fxblue, collective2, myfxbook, fbs_tape) are the retail equivalent of a 13F: delayed, partial, and structurally incapable of revealing a system. Judge a source by its MEASURED candidate yield, never by how much data it returns -- rows are not evidence.

## Evidence

2026-09-14 on the trading box, miner_candidates.json per_source: fxblue 9,280 rows -> 0 candidates; darwinex 5,826 -> 0; myfxbook_outlook 233 -> 0; collective2 232 -> 0; fbs_tape 82 -> 0. All five copy-trade sources together: 15,653 rows, exactly 0 candidates. Meanwhile broker_swaps yields 0.00451 candidates/row and anomalies 0.00021 -- a 21x spread that nothing currently reads.
