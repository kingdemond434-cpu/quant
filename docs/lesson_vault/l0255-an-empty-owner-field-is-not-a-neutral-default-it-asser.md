# L0255

An empty owner field is not a neutral default -- it asserts that nothing on the tree does the thing, and the frontier miner spends its hours on whatever that list names. Four of the twelve 'capability groups with no module' already had real owners: CACHING (experiment_cache.py, P39), ENSEMBLES (family_ensemble.py, a weighted vote over member cells), GRAPH_MODELS (cross_asset_graph.py) and CAPACITY (written that same day and then not registered). Audit the registry against the tree before treating its gaps as research priorities.

## Evidence

unaddressed() reported 12; reading the tree showed 8. ensemble_optimizer.py was NOT a match -- it optimises a portfolio by returns, not predictions by error independence -- so the audit has to read what a module does, not what it is called.
