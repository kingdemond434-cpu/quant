# L0300

A board that reports a family BLOCKED on an input is reporting a BELIEF. Test the loader the build path actually calls before accepting it -- the input is often already present and the real gap is that nothing ever generated cells.

## Evidence

2026-09-12: all seven REACHABLE breadth families read BLOCKED. Every loader returned data: _cot_frame 1,392 weekly obs from a 26-year cache, _macro_series 27,793, _event_index 57, _tape_series spread+flow on every symbol, _bars 37,366. Nothing was blocked on data; 814 cells closed all eight families.
