# L0263

A coverage requirement must be routed by lane. Single-name equities are traded on news and never hunted for statistical hypotheses (principal 2026-09-06), so demanding the full chart ladder for 69 share CFDs would report a deliberate policy as a defect AND spend the download budget filling it. Route by asset class from MetaTrader's own registry, never a symbol list -- a ticker is what lies about a share CFD called 3M. And unknown is not permission: an unroutable symbol is UNCLASSIFIED, not hunted.
