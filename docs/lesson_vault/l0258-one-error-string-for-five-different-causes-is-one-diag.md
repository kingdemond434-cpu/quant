# L0258

One error string for five different causes is one diagnostic for none of them. 'no seat: export OPENROUTER_API_KEY' is emitted whether the key is absent, under another name, in a file that does not parse, in the wrong directory, or set in an environment the Task Scheduler cannot see -- and those have five different fixes. A dark seat does not stop the desk, it makes it PRODUCTIVE AND STERILE: miners keep producing rows, the deepening worker rejects every one, and the board reports 'miners are producing rows and no survivors'.

## Evidence

world_crawler worked 910 tasks and rejected 910; llm_seat reads <repo>/data/secrets/llm_panel.json, and putting it under desks/mt5/data/secrets/ is the obvious miss
