# L0130

When a primary source is login-walled, hunt its REIMPLEMENTATIONS before logging the wall as a blocker. Whoever rebuilt the thing had to resolve every semantic the official docs elide, and their README's bug list names precisely the parts that are hard -- so the wall often costs nothing. And when any fetch fails, name WHICH SIDE failed: ours-vs-theirs decides whether the finding is 'fix the tool' or 'the ground is closed', and those route to opposite organs.

## Evidence

2026-08-12: platform.worldquantbrain.com/learn returned a JS shell (title only), while the GPL-3.0 reimplementation efJerryYang/worldquant-brain-simulator was fully open and yielded the entire post-processing pipeline the docs never state (neutralize->truncate->normalize), rank()'s exact scaling, and decay_linear's weights -- plus three defects in the public alpha101 lineage incl. a bfill look-ahead. Same run, opposite direction: fetch_video_transcript.py failed on all 4 Piped proxies (500/502/301/DNS) while www.youtube.com returned 200 -- a DESK-side outage the coverage protocol would have recorded as a source-side wall (R0527).
