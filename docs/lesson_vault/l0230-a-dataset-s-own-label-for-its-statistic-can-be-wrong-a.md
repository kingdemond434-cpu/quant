# L0230

A dataset's own label for its statistic can be WRONG at one frequency because it was inherited from another -- test the claimed statistic against its alternatives before building on it. And liveness is max(observation_date) PER SERIES, never per dataflow: dead members hide inside a live container with no error.

## Evidence

BIS WS_XRU: all 1,067,834 daily rows are titled 'Average of observations through period' with COLLECTION=A, but the mean of the day's hourly closes scores 18.89 pips on GBPUSD against 6.82 for the single 14:00 snapshot -- a point-in-time CET-clock fixing, not an average (DST-stable at h=14 in both seasons, unanimous across 16 currencies). In the same pull 8 currencies (BHD/IRR/KZT/NPR/PKR/TND/VEF, 2018-2019) are dead inside a dataflow whose last observation is 2026-08-25.
