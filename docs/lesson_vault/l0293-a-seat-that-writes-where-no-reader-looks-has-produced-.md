# L0293

A seat that writes where no reader looks has produced nothing, however good its protocol and its gate. Before crediting an organ with output, trace its artifact to the consumer's read path IN CODE (the compiler's roots, the docket the gauntlet drains): a ledger with no scheduled reader is a write-only file, a gitignored path never leaves the machine that wrote it, and 'zero promotion authority' must never mean zero path to the gauntlet. The measurement of an LLM seat is its row in the compiled artifact's per-source conversion, not its log.

## Evidence

2026-09-08: scripts/kimi_hunter.py wrote admitted findings to data/suggestion_ledger.jsonl and data/kimi_hunt.json (gitignored by `data/*`; readers research_exchange.py and meta_architect.py on no timer and in no manifest row) while desks/mt5/research/miner_candidate_compiler.py reads only data/intelligence/**; libs/ops/deepseek_cycle.py donated to the right tree but its `family`+`symbols` rows had no `params` and fell to the prose path, which ignored the declared instruments. Zero seat rows had ever been counted by the compiler. Fixed: kimi `_donate` into data/intelligence/kimi/, compiler STRUCTURED_HYPOTHESIS branch, declared instruments read before prose, `seats` block in miner_candidates.json.
