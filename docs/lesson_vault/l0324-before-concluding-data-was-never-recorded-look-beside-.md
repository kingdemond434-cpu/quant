# L0324

Before concluding data was never recorded, look BESIDE the artifact you read. A summary row is not the whole record: check for a sibling ledger, a log, a corpus. 'It cannot be built' is a strong claim and the cheapest way to be wrong.

## Evidence

2026-09-14: I read a shadow row, saw only n/cum_r/exp_r/max_dd_r, and told the principal strategy_paths.json could not be generated because per-period returns were never recorded. shadow_forward writes ledger_<sym>_<fam>_<win>.json beside every row with entry_time, exit_time and r_multiple per trade -- 173 of them already on disk. The file built in one pass from data that had been there all along.
