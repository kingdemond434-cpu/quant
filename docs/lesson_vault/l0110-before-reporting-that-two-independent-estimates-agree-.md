# L0110

Before reporting that two 'independent' estimates agree, measure how much of BOTH is the same shared input. Two cost bases agreeing at ratio 0.948 looked like independent corroboration; 91-99.75% of each number was the same quoted half-spread read off the same snapshots, so the agreement was near-tautological. Publish the shared-input share NEXT TO the agreement, and weight the DIVERGENCES.
