# L0202

A publication-lag-correct null is worthless until a LEAKED-signal positive control proves the harness can see anything. Feed sign(next-day return) back as the signal: if it does not return a huge t, your null is a dead pipe, not a result.

## Evidence

data/official_sector_normalisation_sweep.json 2026-08-28: 16 pair-arm cells across MoF/SNB/CNB/MNB all null (max |t|=2.29 on 24 trials); the leak control returned t=+43.1..+55.1 on all 6 pairs, which is the only reason the 16 nulls are readable as nulls
