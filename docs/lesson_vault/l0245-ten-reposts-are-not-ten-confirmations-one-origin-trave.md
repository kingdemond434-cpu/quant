# L0245

Ten reposts are not ten confirmations. One origin travelling through a forum, two aggregators and a translation arrives as four rows, and any counter reading that as four independent sources has built a machine that believes whatever propagates fastest -- worst in exactly the multilingual ecosystems the desk was told to mine. Count ORIGINS by near-duplicate clustering, and a site repeating itself is not a second witness.

## Evidence
