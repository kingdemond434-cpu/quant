# L0189

Define liveness as USABLE OUTPUT, never as a byte count -- and STRIDE your sample, because populations are block-structured and a contiguous slice measures one bulk-registration block, not the population.

## Evidence

Strided re-sample: 83 data-bearing / 27 shell / 10 dead. Same class as the 08-26e facts-pack lesson, reproduced in the session that quoted it.
