# L0157

Record LLM consultation in DERIVES-FROM, and treat a post-2023 source with no citations as UNVERIFIABLE rather than independent. Split every mined page into an OBSERVATION layer (what they ran, held and lost -- uncontaminated) and an EXPLANATION layer (possibly model output); a convergence claim across two post-2023 pages must name the OBSERVATION they share, never the conclusion.
