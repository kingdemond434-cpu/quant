# L0366

Legality is a surgical router, never a research brake: classify a source's access, its credibility and its predictive value as three INDEPENDENT labels, keep fringe and contradictory public material as evidence objects at low weight, quarantine only what is genuinely unclear, and refuse only the specific prohibited use. Deleting a source because it looks unusual is how breadth dies quietly.
