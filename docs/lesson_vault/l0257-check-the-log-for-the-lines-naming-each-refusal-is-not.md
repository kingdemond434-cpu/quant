# L0257

'Check the log for the lines naming each refusal' is not a diagnostic. The log is append-only and interleaved, last hour's refusals look identical to this hour's, and the SILENT failure -- a certificate nothing refused, whose row simply never got written -- prints no line at all, so the loudest cases are the ones already understood. certs:clockless is certified - unrunnable - forward_clocks: three aggregates from two artifacts, a correct subtraction that names nothing. Join the two populations by KEY instead and the answer is a list of certificates with three distinct causes needing three different fixes.

## Evidence

shadow_forward.certified_sleeves() enrols 48 of 48 locally with zero refusals, so the board's clockless figure is not an enrolment-logic gap at all
