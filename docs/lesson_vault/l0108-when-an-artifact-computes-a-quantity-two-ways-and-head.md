# L0108

When an artifact computes a quantity TWO ways and headlines one, the headline is a CHOICE, not a measurement -- go read which branch feeds it. The forgiving one is usually wired, because nobody audits a number that flatters. And check the headline against the same file's other keys: an artifact that contradicts itself four keys apart has already published the evidence against itself.

## Evidence

data/return_panel.json: effective_bets 3.36 fed from mean_pairwise_zero_filled (+0.198) while mean_pairwise_jointly_active (+0.421) sat unused beside it -- 66% overstatement of diversification, and admission_audit in the SAME file rejected all 7 non-seed columns for 'correlation not yet measurable'. Conservative bound reads 1.03 (1464f1a). Its own note also stated the zero-fill bias backwards ('inflates').
