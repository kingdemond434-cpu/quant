# L0001

A heartbeat proves the loop is alive, NEVER that the pipe is. Every listener needs a second signal -- time since the last real payload -- or a silent block looks exactly like a quiet market.

## Evidence

liquidation_listener held a fresh heartbeat and reported LISTENING for 14 days while archiving ZERO events; Binance completed the WS handshake and dropped every data frame. institutional_knowledge.md, 'Heartbeat liveness != data liveness'
