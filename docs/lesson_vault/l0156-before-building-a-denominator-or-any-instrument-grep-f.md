# L0156

Before building a denominator or any instrument, grep for one that already exists UNREAD. An existing measurement with no consumer looks identical to a missing measurement from the fence's side, and only one of them needs building.

## Evidence

2026-08-13: R0570 said 'nothing counts attempts' for panel seats. True per-seat -- but data/audit_coverage.json budget_history had recorded {blanked, of} per RUN for 28 runs the whole time: 70 of 148 seat-calls = a 47% aggregate blank rate that three organs (seat-chronic fence, check_free_roster, model_upgrade) all reasoned about seat health without ever reading. Rowed R0583.
