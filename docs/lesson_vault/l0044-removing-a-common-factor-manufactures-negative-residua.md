# L0044

Removing a common factor manufactures negative residual correlation. Compare residual correlation to -1/(N-1), never to zero, or the demeaning arithmetic reads as diversification.

## Evidence

effective_bets reported 64.4 independent bets from 29 perps; the demeaning floor at N=29 is -0.0357 and the measured residual was -0.0196. demeaning_floor() in libs/research/cohort_independence.py
