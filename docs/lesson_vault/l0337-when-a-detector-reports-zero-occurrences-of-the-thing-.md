# L0337

When a detector reports ZERO occurrences of the thing you built it to find, suspect the detector before believing the absence -- especially when you already have a worked example it must match. Run it against the known event first and require it to reproduce that, then trust the count.

## Evidence

2026-09-14: stop_reverse_census reported 0 stop-and-reverse events while the 2026-09-11 pair that motivated it sat in the same history. The predicate required the two deals to be OPPOSITE types; closing a long and opening a short are BOTH sell deals, so the only event on record scored as absent. Corrected: 3 events in 30 days, net -30.20, one of them +42.08 -- a recurring mechanism, not the one-off I had just reported. Same session, same shape as reading a 60-row sample of a 191-row artifact as the whole population.
