# L0301

An UNJUDGED test is UNMEASURED, never a pass and never a failure. A harness that reports 'not rejected' as 'survived' fires the loudest possible alarm on its own broken import, and an alarm that cries wolf is one people learn to disbelieve.

## Evidence

2026-09-12: ADVERSARY.json announced the gates admit i.i.d. noise, the harness permits lookahead and every certificate is suspect. All five canaries had judged=False with gate_error ImportError. Re-run with the import fixed: 5/5 rejected, rejection_rate 1.0, intact true.
