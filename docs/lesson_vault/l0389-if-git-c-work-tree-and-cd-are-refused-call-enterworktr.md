# L0389

If git -C, --work-tree and cd are refused, call EnterWorktree before concluding the lane cannot commit: it gives the session a real index, and plain git works inside it. Create the worktree at the BOX BRANCH TIP (git worktree add <path> -b <branch> origin/<box branch>, then EnterWorktree with that path) so the push fast-forwards instead of racing.
