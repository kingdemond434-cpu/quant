# L0384

When a producer is dark, MEASURE WHICH OF THE FIVE CAUSES IT IS before repairing: they share no remedy. (1) A CLOCK ON THE WRONG MACHINE -- kimi held a VPS timer while its credential lives on the box, so the clock could fire forever without producing; the remedy is a clock where the credential is, and the box's clock index must read EVERY ops/*.service, not only quant-*. (2) A SEAT RETIRED WITHOUT AN INHERITOR -- three MQL5 seats were retired with a replacement named and mql5_reputation was left to read DARK forever; a retirement with no inheritor is an abandonment and the census now says so by name. (3) AN ENVIRONMENT PROVISIONED ON THE WRONG BOX -- the federation's shared venv was built on the 8 GB build box while the trading box with the data and the compute planned 13 runnable against 52 unmeasured; provision where the compute is. (4) A MAPPING TABLE NEVER FILLED IN -- 92 of 105 seats read UNMEASURED because SEAT_ORGANS held 14 hand-typed rows and FOUR of those pointed at files that never existed; derive the mapping from the source tree so a seat that lands today is mapped today, and treat a mapping gap as a defect IN THE MAPPING, never a licence to report UNMEASURED. (5) AN EXECUTABLE THAT LANDED WITHOUT A LEG -- give it a leg or a retirement row with a reason, and keep that ratchet in the birth fence so one number never carries two ratchets that can disagree. And judge a producer only where its clocks actually live: os.name says Windows on the trading box AND on every build box, whose data/intelligence is a git mirror, so MEASURE whether the scheduled tasks are registered here before calling a hundred healthy seats dead.

## Evidence

MEASURED on the trading box VMI3500897 2026-09-23: check_seat_health read 105 seats, 92 UNMEASURED for the single reason 'no organ declared in SEAT_ORGANS' while sixty of them were producing inside the hour; the producer census that replaced it read 1,480 producers. Sandbox importable systems 13 -> 30 of 58 after provisioning on the trading box (+17 in one pass). kimi ran rc=0 and donated nothing because its own frontier gate declined the pass ('all 130 known territories are picked over; next opens in 34d') -- a clean exit is not production.
