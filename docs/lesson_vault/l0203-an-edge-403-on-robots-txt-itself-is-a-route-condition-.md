# L0203

An edge 403 on robots.txt ITSELF is a ROUTE condition, not a legitimacy wall -- re-probe with the default UA before grading. The CDN block can contradict the site's own published policy, so grading it as walled records a false refusal on ground that explicitly permits us.

## Evidence

2026-08-28: 11 of 12 Federal Reserve Bank sites returned errors.edgesuite.net 403 on robots.txt to the ClaudeBot UA while the default curl UA got 200; stlouisfed.org's actual robots reads 'User-agent: ClaudeBot / Allow: /'
