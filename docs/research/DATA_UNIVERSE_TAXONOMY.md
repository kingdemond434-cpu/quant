# The data-universe taxonomy — the hunting map, not a checklist

**Installed 2026-08-04 by principal order.** Thirty domains and the bulk name-list below are the
STANDING UNIVERSE every breadth organ hunts against, every day. The order is explicit that this is
"an ongoing discovery process rather than a checklist you eventually finish": new features and
combinations can be created indefinitely, so the taxonomy itself must GROW — the breadth organs'
job on every cycle is (1) diff the desk's live coverage against this map, (2) push every funded
seat for bulk additions (one-word dataset names by the hundreds — cheap rounds, full ladder, never
a first answer), and (3) convert the diff into hypotheses, collectors, and axes in the standard
pipeline. A domain with no measured axis is a named gap, not background.

Re-swept weekly at minimum (this file's own cadence, enforced by §36); the DIFF runs daily inside
`breadth_expander` / `run_cro` whose dossiers carry this file in full.

## The standing questions every cycle asks of every candidate axis

Is there new information? Is it predictive? Can we measure it? Can we collect it reliably? Can we
trade it after costs? Does it survive out of sample at the full bar? Does it DIVERSIFY what the
desk already holds (marginal admission, never standalone merit)?

## What this file must never become

A list somebody reads once. It is INPUT to `breadth_expander` and the CRO dossier (both carry it
whole), its coverage column is re-verified on this file's own §36 cadence, and every "named gap"
row above owes either a collector, a hypothesis, or a dated reason it is not worth its build cost.
The gauntlet stays where it is: this file expands what gets TESTED, never what gets believed.
