## WHAT WAS BUILT

Measures reachability from the **declaration site** (`ast`-parsed), not from the tally. Statuses:

declaration site.

*"rejects ~100pct **or accepts ~100pct**"* for weeks while the code did only the reject side --

never be flagged. Now wired to the declared roster; fires `gate-optimality-accept-side`.
