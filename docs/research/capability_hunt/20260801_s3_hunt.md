## What was built

### 1. `scripts/check_enforcement_execution.py` — the capability (new)

The generalisation of item 44, and the reason this run built a fence rather than only a fix.
`check_fence_yield` (L1.43) asks what a fence has **caught**. This asks the prior question a
never-run fence cannot answer for itself: **is there a path by which it could fire at all?**

Verified first that no existing check covered it — the desk's most common defect is rebuilding
something already present:

| check | why it was blind |
|---|---|
| `build_enforcement_matrix.py` | checks a citation **exists** and **maps**. Never execution. |
| `max_audit.check_orphan_code` | **PACKAGE**-granular, skips packages with <3 modules. `libs/research` is reached by dozens of scripts, so an orphaned **module** inside it is invisible. |
| `check_fence_yield.py` | scoped to fences that emit **artifacts**; a library module emits none. |

All three were green across the defect.

**`IMPORTABLE IS NOT EXECUTED`** is the load-bearing distinction. `libs/validation/__init__.py`
re-exports `RevalidationController`, so `revalidation.py` is statically reachable from anything
importing `libs.validation` — naive reachability would call it live. So a module counts as EXECUTED
only when one of its own public symbols is **referenced from non-test code**, never because an
`__init__` re-exports it.

Statuses: `EXECUTED / STANDING / TEST / MANUAL / DECORATIVE / MISSING`; run status
`OK / DECORATIVE / MISSING / UNMEASURED`. Zero citations reports **UNMEASURED, never OK** (L1.28a —
the exact bug that let this defect live behind a green matrix).

Deliberately conservative, because a gate that cries wolf gets acknowledged into silence and that is
how enforcement actually dies: ambiguous cases resolve to EXECUTED, and human-invoked tools are
exempt **with a recorded reason** (the "no cron line must be a DECISION" convention).

## Three defects found in my own build, before shipping

Recorded because each is the exact class this desk keeps rediscovering.

1. **The fence cited itself as evidence.** `deep_review.py` flipped to EXECUTED because the

3. **The wiring was welded.** First run returned `SHIFT` on **both** axes with an identical 0.35
   haircut — the welded-gate signature. Cause was mine: I fed **raw levels**, and a two-window test
   fires on any trending series (a benign drifting random walk returns SHIFT; measured). Fixed by
   testing the signal **in the form the strategy consumes** — the causal trailing z-score. It now
   discriminates: kimchi STABLE, stablecoin SHIFT.

## The judgement call: only SHIFT strips capital

`DRIFT` **is** a member of `_HARD_TRIGGERS`, so wiring it would block `production_capital_allowed`.
It fires on a single marginal indicator, and at `n_ref=659 / n_recent=220` the KS 5% critical value
is ~0.106 — badly overpowered — while financial autocorrelation violates the iid assumption KS rests
on. Measured: a benign drifting random walk returns DRIFT.

So the caller maps **only SHIFT** to a hard trigger. This is faithful to the producer's own
documented semantics (`dist_shift` is explicitly advisory: "the caller decides, and the caller logs
the decision"; DRIFT "flags, it does not conclude"). Blocking capital *is* concluding. SHIFT needs a
break-magnitude move or corroboration between two independent views — that is the defensible bar.
A clamp that fires on nothing real is a compounding cost, not prudence (L1.27/L1.28). Band
re-calibration rowed as **R0229** rather than hand-tuned mid-build.
