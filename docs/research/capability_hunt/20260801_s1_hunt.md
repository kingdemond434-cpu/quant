## Two bugs found and fixed in this run

1. **The fence crashed on a malformed row.** My own test (`funding_rate: "junk"`) killed it with
   `ValueError`. A fence that dies on bad input publishes nothing — the worst failure mode for an
   instrument whose entire purpose is "unmeasured must never read as OK". Fixed with `_num()`,
   which returns `None` (counted as `n_malformed_closes`, surfaced as an `UNREADABLE` breach)
   rather than coercing junk to `0.0` — a zero funding rate reads as *"this close forfeited
   nothing"*, the reassuring direction and therefore the dangerous one.
2. **A test that would have certified the defect.** My first delta test used a 24h hold and
   asserted a non-zero spread. It failed, correctly: 24h is *exactly* 3×8h, the one case where
   the accrual is exact from every phase. `_MIN_HOLD_H = 24.0` is exactly at that point — the
   accrual is right at the floor and wrong everywhere above it, which is a further reason it
   looked defensible. Test rewritten at a 20h hold, where every trade is wrong and the mean is
   still zero.
