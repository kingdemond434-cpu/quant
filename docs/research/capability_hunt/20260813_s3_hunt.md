The falsifier resolved **in favour of the build**, but it also corrected the proposal. The
proposal wanted to borrow the desk's 20.47-of-29 residual-*return* breadth. That is the wrong

the cross-sectional correlation of the **summands**, not of the returns. The RAW row is why the
2026-08-11 change looked right; the RELATIVE row is why it is wrong here *and* why the pre-08-11
endpoint is wrong (it returns the full K by construction — the exact misreading `effective_bets`
was clamped to prevent after "64.4 independent bets from 29 perps"). Only the PRODUCT row is both
measured and relevant, and it lands near neither endpoint. Independently derived correction:
**9.6× in the detection floor, not the proposal's borrowed 9.9×.**

**Design decisions that matter.**

*Absence is a refusal, not a default.* An unmeasurable panel keeps the **conservative full-K
divisor** it has today. The change moved not one recorded number by itself — every existing test
of the old behaviour still passes bit-identically.

*An unmeasured panel can never be `powered`.* This is the load-bearing half and it strictly
TIGHTENS. `powered` is what licenses SCREEN-WEAK, the desk's only graveyard-grade negative
verdict; certifying "tested and refuted" on a sample size nobody measured is the false-null
direction no other gate catches, and it is exactly what produced the 42 SCREEN-WEAK verdicts
`screen_oi_ls_axes.py:126` records as ones "the screen lacked the power to make".

*Measured per panel, per cell.* Asserting a desk-wide constant would re-create the same error in a
third place.

*Coverage is a ratchet, not a cliff.* Legacy assumed cells read PARTIAL and exit 0 (L1.0/L1.43);
only an OVERCLAIMED cell fails; an empty scan set reads UNMEASURED, never OK (L1.28a).

drops rows (L1.60), committed by the fence built to respect it. Repaired with `_paths()`

**The change would have manufactured 32 contradictions, caught before commit.**
`scripts/run_type2_report.py` re-derives `powered` from each recorded cell and labels a mismatch
against the recorded flag `DISAGREES`. Its recompute went through `correlation_negative`, which
did not forward `xs_neff` — so it would have used the full-K divisor while the screen had used the
measured one, and **every one of the 32 newly-measured cells would have been labelled a
disagreement**: an L1.61 contradiction created by the reader rather than found by it, landing on
exactly the cells least able to defend themselves. `xs_neff` is now threaded through
`correlation_negative`, and `test_the_type2_reader_cannot_manufacture_a_disagreement` fails if the
thread is cut. This is the L1.61 lesson arriving one day later in a new place: a fix in one copy
of a shared expression leaves the other authoritative.

## Honest uncertainty

The breadth estimate is **sensitive to the column-inclusion floor**: pairwise-complete over all
139 names gives **92.76** bets; restricting to columns with ≥200 observations (pandas
`min_periods=200`) gives **72.27**. Both are far from 1 and far from 139, so the conclusion — the
divisor is ~1.5–1.9, not 139 — is invariant, but the *level* is not pinned to better than ~±30%.
The deflator moves as sqrt, so that is ~±15% in the detection floor. Recorded rather than smoothed
over. A drift monitor (breadth measured once is a fossil; correlation regime-shifts) is **not**
built — rowed.
