## What was built

**`libs/research/print_impact.py`** -- the estimator.

- **Unit of observation is the INTER-SNAPSHOT INTERVAL, not the print.** Depth polls every
  ~5-8.8s while prints arrive continuously, so dozens of prints fall between two snapshots and no
  single print's displacement is separately observable. Aggregating net signed notional per
  interval against the mid change across it is Kyle's lambda properly specified, uses every print,
  and turns the cadence limit into an aggregation rather than a bias.
- **Ordering is by FILE POSITION (receipt), never by timestamp (L1.46).** Binance depth rows are
  receipt-stamped (`c="recv"`) and trade rows carry **only** the venue stamp (`c="venue"`, no `r`
  field), so the two `t` values are different clocks. `clock_provenance.sort_key` cannot rescue
  this -- for a Binance trade row `recv_ms` returns None and the key falls through to the venue
  `t` while depth keys on receipt, silently interleaving them. File order is receipt order in both
  corpus eras and needs no timestamp arithmetic, so it cannot commit the cross-clock error.
- **Confound control, and its ceiling stated.** A second slope controls for the previous
  interval's return; both are published with `momentum_share`.
- **n_eff, not n (GAP REGISTER row #100).** Every CI is deflated by the AR(1) factor
  `(1-rho)/(1+rho)`, taking the more autocorrelated of residual and flow, clipped so negative
  autocorrelation can never inflate n_eff above n. `n_eff` -- never `n` -- gates the verdict.
- **Extrapolation guard (L1.45 applied reflexively).** `cost_bps(N)` refuses above the p99 of
  observed net flow. Asking a fit about an order larger than any flow ever observed is inventing a
  counterfactual, which is the book walk's error committed by the other basis.
- Statuses `MEASURED` / `UNDERPOWERED` / `UNIDENTIFIED` / `NO-DATA`; `cost_bps` returns **None,
  never 0.0**, when unmeasured -- a book with no measured cost is not a free book.

**`scripts/fit_print_impact.py`** -> `data/print_impact.json`. `guard()` at entry (L1.42),
`Inputs` provenance (L1.55, `cost_model.json` declared `required=False` because the fit depends
only on the tape), rollup denominator counted from what the run **found** (L1.57), and
`UNMEASURED` on an empty scan -- never OK (L1.28a).

**`tests/research/test_print_impact.py`** -- 20 tests. Aggressor sign pinned in **both**
conventions (Binance `m=True` is a SELL; Bybit `side` names the aggressor directly -- inverting
one and not the other would make bybit fits the mirror image of binance fits and both would still
read MEASURED). File-order assignment pinned with a deliberately misleading venue timestamp, so
the test fails if anyone "tidies" `intervals()` into sorting by `t`. A **positive control** that
plants lambda=0.5 bps/$1k and requires recovery -- the desk's own `certify_gauntlet` lesson, that
an instrument never shown to PASS a known-good input has only had its refusals observed.

**Governance.** Mapped to L1.45 in `build_enforcement_matrix.py` (0 orphan fences), registered in
`check_build_standard._GOVERNED` (73/73 OK), scheduled as the `print_impact` step of

## First run

Full 3-venue, 24h-per-symbol pass, 11m34s wall:

```
MEASURED -- 99 of 124 fits measured; 34 symbols priced on both legs at $450
  by_status: {MEASURED: 99, UNDERPOWERED: 22, UNIDENTIFIED: 3}
  spread vs impact: impact is 1.6% of cost at $450
  vs book walk: n=34, median ratio 0.948 (independence: LIMITED)
  falsifier: UNDERPOWERED -- 4 paired symbols
```

**The headline is not the 0.948, and the artifact says so in its own text.** Impact is 0.25-8.6%
of the print-basis cost at $450, so 91-99.75% of *both* bases is the same quoted half-spread read
off the same depth snapshots. A ratio near 1 is therefore very largely **tautological**, not
independent corroboration. Publishing it without that caveat would have manufactured a validation
the data does not support, so `agreement_with_book_walk.independence` carries the warning inline
and the console output prints it.

**Three findings that are real:**

1. **At $450 the desk is a SPREAD TAKER, not an impact maker** (median impact share 1.6%). Cost
   reduction on this book comes from passive placement and symbol selection -- **never from
   slicing**. Trading in smaller clips cannot recover a cost that is ~97% half-spread. The blended
   book-walk number cannot express this; it is a genuinely new operational answer.
2. **Four books where the walk charges ~2.3x the print basis**: CELRUSDT 0.403, ZENUSDT 0.434,
   TSTUSDT 0.442, GTCUSDT 0.459. These are where displayed depth is thin relative to liquidity
   that actually trades -- and where the two bases are genuinely independent (highest
   `impact_share`). This is where research should go, and it is the opposite tail from where a
   naive reader would look.
3. **The estimator's own ceiling, found by its own test and then pinned.** My first
   momentum-confound test failed, and the test was right: the lagged control removes flow that
   *chases* a past move but cannot touch **simultaneity inside the interval**. A synthetic book
   where flow is a pure function of the contemporaneous return -- causing none of it -- still fits
   a large, highly significant lambda. That limitation is now in the module docstring, asserted by
   `test_contemporaneous_simultaneity_is_NOT_removed_and_that_is_documented`, and is the reason the
   basis carries zero promotion authority. Observational data cannot resolve a counterfactual
   (L1.45); excitation remains the only instrument that can.
