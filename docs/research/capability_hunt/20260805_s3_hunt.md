## 3. WHAT I BUILT

### The fail-safe (the one piece of genuinely new design)

`libs/research/slot_registry.cohort_m_for_bar() -> CohortM(m, provenance, detail)`.

The reason this is not a one-line `len()`: **`derive_slots()` can degrade, and its degraded output
is a LOWER BOUND on `m`.** Using it raw means an unreadable file silently loosens every bar on the
desk -- the same failure, arriving by a different door. So every degraded path floors **UP**:

| state | `m` returned | provenance |
|---|---|---|
| all sources readable | measured count | `MEASURED` |
| a source unreadable (m is a lower bound) | `max(m, 12)` | `INCOMPLETE-FLOORED` |
| registry unusable entirely | `12` | `REFUSED-FLOORED` |
| cohort over cap | true `m` (cap limits clocks that may RUN, not the bar they pay) | `MEASURED` |

The asymmetry is the whole argument: over-counting costs a real edge a few days of clock;
under-counting admits noise as edge and sizes capital on it. `concurrent_m()` now delegates here, so
the previously-dead function is safe-by-default for whoever calls it first.

### Wiring (3 sites)

- `scripts/run_axis_shadows.py` -- **the money-path repair.** Bar moved **2.13 -> 2.61** on the
  live clocks. Artifacts now record `m_concurrent` + `m_provenance`, so a bar is auditable from its
  own artifact instead of inferred from source.
- `scripts/run_alerts.py` -- `slot_budget_exceeded` made **reachable** (was `6 > 12`); added
  `slot_cohort_incomplete`.
- `scripts/meta_research_review.py` -- now reports **11/12 used, 1 idle** (was `0 used / 12 free`).
  This feeds `record_desk_metrics.py:95` and the §2 bottleneck evidence, so the desk was ranking
  its own binding constraint off a two-source-of-truth violation. Its failure path returns `None`,
  not `0` -- and `record_desk_metrics` gates on `isinstance(..., (int, float))`, so an unmeasured
  cohort is now *omitted* rather than recorded as twelve idle seats (L1.28a).

### The fence -- `scripts/check_cohort_integrity.py` (new, RAIL)

Statuses worst-first, every empty-input case ranking above OK: `NO-DATA` / `UNMEASURED` /
`BAR-TOO-LOOSE` / `COHORT-INCOMPLETE` / `DIVERGENT` / `OK`. Exit 2 on anything but OK.

Two deliberate design choices:
- **Pure stdlib, recomputing the Holm threshold from `NormalDist` and cross-checking against the
  shipped `holm_bar`.** `holm_bar` lives in a numpy-importing module, and a fence a missing
  dependency can silence is not a fence. Cross-check currently reads `agrees`.
- **AST, not regex** -- see §5.

### Tests -- `tests/research/test_cohort_integrity.py` (16 tests, the module's first ever)

Every test is **directional**: it asserts the *sign* of each failure mode. A fail-safe that floored
the wrong way would pass a naive "returns an int" test while doing exactly the damage it exists to
prevent.

### Governance

  it never said the bar is a *function of m* and that m has one source, which is precisely how it

file, made the scanner read `utf-8-sig` so a future BOM cannot blind it, and added
`test_no_tracked_python_file_carries_a_byte_order_mark` as a standing guard.

**(c) `run_axis_shadows.py` was scheduled NOWHERE** -- absent from `ops/crontab.manifest` and from
