## What each column means

- **disposition** -- DIRECT/WRAPPED run upstream code in the sandbox; REBUILT reproduces the mechanism in desk code; REJECTED_WITH_EVIDENCE carries the licence reading that refused it; ADAPTER_ONLY is an adapter with no seed row.
- **runs here** -- the module imported in the shared sandbox venv, or the system is desk code. NO is never silent: the status column names the exact reason.
- **breadth** -- marginal independent breadth: how much of the federation's effective rank disappears if this system stops donating (participation ratio of the system x cell indicator matrix).
- **last run (h)** -- hours since the rotation last gave it the hour; `-` means it has never run. `scripts/check_sandbox_liveness.py` fails on any runnable system past its rotation window.
