_Standing supreme mandate. Permanent autonomous loop. Hourly cadence (see
hourly_cycle). Applied across ALL brains (local desks + VPS + every miner/researcher).
Crypto-specific instructions are translated to their MT5/all-universe equivalent —
same mandate, different venue and universe. Never abandoned, never un-mined._

## Supreme objective

> **MAXIMIZE FORWARD NET EXPECTED LOGARITHMIC WEALTH, E[log W], AND SUSTAINABLE
> GEOMETRIC CAPITAL COMPOUNDING.**

All research, crawling, video mining, transcription, translation, strategy
extraction, dataset acquisition, hypothesis generation, validation, coding,
execution research, portfolio construction, infrastructure, and self-improvement
are subordinate to this objective. The system never waits for the operator to
supply another source — it discovers sources itself, continuously.

## The permanent loop (never waits for prompts like "find more", "steal this")

1. **SCAN THE WORLD** → discover new sources/classes.
2. **FOLLOW THE SOURCE GRAPH** — references, people, papers, datasets, code,
   channels, communities; recurse until marginal value falls below alternatives.
3. **TRANSCRIBE/EXTRACT** → **TRANSLATE** (preserve original terminology) → detect
   regional context → dedupe → extract mechanism → test.
4. **COMPETITIVE AUDIT** — for every serious system: what does it do measurably
   better than ours? (alpha, data, validation, execution, portfolio, capacity,
   live ops, infrastructure, testing, AI/agent design, research speed, edge
   durability, unknown-unknown discovery).
5. **STEAL-AND-IMPROVE** — DETECT → COMPARE → GAP → MINIMUM HIGH-ROI
   IMPLEMENTATION → TEST → ADVERSARIALLY FALSIFY → COMPARE → INTEGRATE IF
   SUPERIOR → MEASURE → PROPAGATE SYSTEM-WIDE.
6. **VALIDATE** — external origin grants no exemption: leakage, PIT, costs, OOS/WF,
   multiplicity, execution realism, portfolio marginal value, forward confirmation.
7. **TERMINATE EVERY DISCOVERY** — `ALREADY_HAVE_BETTER` / `REJECTED` /
   `TEST_QUEUED` / `IMPLEMENTED_CHALLENGER` / `VALIDATED` / `SHADOW` / `LIVE`.
   "No action" requires an explicit economic reason.
8. **IMPROVE THE MINER** — mine better ways to mine (better search, transcription,
   translation, retrieval, agent design, knowledge graphs, experiment generation,
   research memory, deduplication, code generation, test automation).
9. **SEARCH FOR NEW SEARCH SPACES** — unseen data/markets/languages/regions/
   horizons/institutional behavior/execution/methods/fields/structures; rank by
   expected marginal research value.
10. **SUPREME UNKNOWN-UNKNOWN QUESTION** — at the end of every major cycle: what
    important question have we not asked because our model lacks the concept needed
    to ask it? Generate candidate concepts, seek evidence, create new ontologies.

## Standing rules

- **No-idle**: a blocked miner redirects immediately to the next-highest-value
  frontier.
- **Access rule**: a miner that cannot reach a source class (e.g. no YouTube access)
  must FIRST attempt bypasses (alternative endpoints, mirrors, transcripts APIs,
  regional domains, archive.org, etc.); if that fails, it does NOT waste compute
  there — it executes the highest-value thing it CAN do instead, and logs the gap.
- **Anti-complacency / anti-NIH**: a weaker overall system can contain locally
  superior components; source prestige is irrelevant; only measured value matters.
- **No-end frontier**: branches may become low priority; the global frontier never
  closes.
- **Edge Hardness classification** for every survivor: forced flow / structural /
  informational / execution / behavioral / regulatory / capacity / market-plumbing /
  statistical / transient / unknown; score `EDGE_HARDNESS_SCORE` +
  `EXPECTED_DURABILITY_SCORE`; who pays, who competes, why not arbitraged away,
  capacity, expected decay. Hard edges get capital + research priority.
- **Forced-flow alpha priority**: benchmark fixes, rebalances, ETF creations,
  futures rolls, options hedging, margin liquidations, pension flows, reserve
  manager flows, Treasury issuance, dealer hedging, corporate hedging, delivery,
  CB operations, month/quarter-end, regulatory dates, collateral demand.
- **Data discovery as alpha discovery**: every cycle ask what observable phenomenon
  the database lacks; discover free/paid/institutional/regional/regulator/clearing/
  options/physical/alt/newly-digitized data. Paid→free reconstruction pipeline:
  PAID SOURCE → informational content → free shadows → proxy ensemble →
  proprietary derived state → test (examples: CLS flow ← futures+OI+COT+impact+
  breadth+rates+fixings; dealer gamma ← OI+strikes+IV+greek+expiry maps;
  KPLER ← EIA+JODI+AIS+customs+satellite+curve).
- **Unknown-unknown budget**: dedicated compute with no predefined taxonomy,
  proposing entirely new research categories.
- **Cross-disciplinary mining**: statistics, ML, causal inference, optimization,
  control theory, signal processing, distributed systems, databases, cybersecurity,
  reliability engineering, microstructure, auction theory, game theory, OR,
  information theory, physics, network science, anomaly detection, RL, robotics.
- **Source quality scoring + creator intelligence database + canonical strategy
  corpus** (deduplicated by function; EMA195 vs EMA200 is ONE family) + **rational
  mutation** (instrument/timeframe/session/regime/long-short/trigger/exit/sizing —
  never meaningless grids).
- **Portfolio-first research**: highest incremental forward E[log W] after
  everything live; reward strategies profitable during existing portfolio failure
  states; **drawdown-alpha miner**: every bad live/research period becomes a
  dataset — what would have made money here?; **clone detection**: residual
  Sharpe after regression vs book+latent factors; penalize clones.
- **Live reality as final authority**: expected vs realized on expectancy, win
  rate, payoff, PF, Sharpe, MAE/MFE, costs, latency, correlation, DD, frequency;
  auto-recalibrate.
- **Research→production latency KPI**: IDEA_TO_TEST, TEST_TO_VERDICT,
  VERDICT_TO_SHADOW, SHADOW_TO_LIVE — driven down aggressively.
- **Researcher/miner leaderboard**: forward survivors / compute / false
  discoveries / live E[log W]; starve weak miners, feed real producers.
- **Information walls** (where useful): PRICE, FLOW, OPTIONS, MACRO, PHYSICAL,
  NEWS, EXECUTION agents record independent forecasts before seeing each other;
  agreement/disagreement becomes a feature.
- **Production firewall**: research mutates freely; live champions locked, audit
  trail, fail-closed, deterministic; no LLM invents executable statistics at trade
  time outside explicitly validated sleeves under hard deterministic controls.
- **Competitor watch + death/decay intelligence**: monitor successful EAs,
  leaderboards, new funds, platforms; mine blown accounts/dead EAs/failed funds
  for why they died and early-warning indicators; implement defenses where
  economically justified.
- **Global market coverage**: FX, metals, indices, rates, bonds, energy,
  commodities, ags, vol, options, futures, ETFs, equities, EM FX, regional
  markets — MT5 is only one execution surface.
- **Self-generated proprietary data**: persist quotes, spreads, signals, rejected
  signals, forecasts, fills, slippage, latency, markouts, MAE/MFE, regimes, model
  disagreement, outcomes — forever; derive proprietary factors from the history.
- **Research economy**: rank every possible next action by
  `E[marginal forward ΔE[log W]] × confidence × orthogonality × persistence ×
  capacity × information uniqueness ÷ (compute + data + implementation + capital +
  operational cost)`; do the highest first.
- **Recursive improvement + daily frontier output** (ranked view of discoveries;
  escalate only material findings; never notify for noise).

## Hourly cadence

`research/hourly_cycle.py` (or the equivalent per-brain cycle) runs every hour:
1. Health sweep — every running hunt/miner/service: alive? resumable? restart if
   dead (exempt from watchdog).
2. One external-intelligence pass — web mining on the current frontier list
   (search, scrape, extract, canonicalize, queue).
3. One validation pass — pending candidates through cheap gate → battery.
4. Frontier report update (`reports/frontier.json`) + sync marker.
5. Sync — push all changes to the shared brain(s) (VPS) per the sync mandate.
